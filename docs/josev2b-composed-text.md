# Josev native text composition

This is a default-off, CPU/F32 batch-one component experiment. It connects
raw SystemOne JSON to the dedicated tokenizer/schema frontend, strict320-tensor
backbone, native tied-embedding lexical means,122-tensor joint head and native
answer serializer. No captured hidden or lexical vectors are inference inputs.

Frozen sources: backbone/qwen decoderab998277, headd8b99a9c,
frontend/serializer5452632d. Main619d719c is merged before edits;
the integration candidate retains ggmla06. The old OCR1024 mapper and other
runtime files stay unchanged. The frontend descriptor rejection must be fixed
from authenticated publisher source, and its own original-first audit must pass
before composed model execution. Answer serializer original-first proof is also
a dependency. The build-only phase does not qualify either component.

`phase=josev-composed-build` on the metadata caller builds two standalone CPU
archives with two workers, verifies off-gate rejection before file access and
checks production archive observer exclusion. No tokenizer/model/reference
payload or framework is downloaded by this phase. All compilation stays hosted.

Runtime gate: `CRISPEMBED_JOSEV_COMPOSED=1`, plus existing backbone, Qwen3.5,
head, text frontend and answer serializer component gates. No process environment
is modified by library code. Explicit component paths are temporary internal
plumbing; public capability/packed GGUF/C/Python/CLI/HTTP/Rust/Dart and aliases
are subsequent work, not claimed support.

Next hosted numerical protocol must authenticate exact remote backbone/head/
tokenizer artifacts and frozen original receipt51a2e16b, then compare all four
raw requests. Require exact input IDs/masks/spans/order,104 backbone stages,
123 head stages, seven lexical/logit/probability groups and complete typed JSON.
Declare unmapped rotary/argument traces explicitly. Use actual crispembed-diff
Ref and independent absolute/mean/RMS/L2/cosine metrics at unchanged0.002/
0.99999, logit0.002/probability0.0001/ordinal0.001 gates. Record every four-place
answer difference. Ordinary/observed/repeat outputs, malformed-input stale-output
clearing and recovery must pass. A test-only observer may throw; its failure must
leave no published response. Never use reference hidden/lexical data as native
inputs. Raw traces/models/binaries remain remote; review only small reports.

Float lexical reduction follows the publisher's mean over actual option-span
embedding rows. Exact GPU/CPU reduction order is unproved; compare this earliest
new stage before attributing a later head difference. No precision, quality,
long-context, media, batching/padding, GPU-backbone or release claim follows.
