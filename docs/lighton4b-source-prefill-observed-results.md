This is **observed calibration, not qualification or a shipping/default change**. It reuses the exact proved binary from `87d39abfe89f925683ca4b586dcd79b025ae9e6d`; no runtime rebuild or reference forward occurs.

Physical weights stay `843e66c31e5516cd6597cf20de544906f75ba024bbcbbab3f2c9085a61e79d43`. GDN source operators, Q4 repack, Q6 tiled arithmetic, corrected Pillow/F16 vision and F16 attention all remain fixed ON; text/head BF16 alternatives stay OFF. Only `CRISPEMBED_LIGHTON4B_PHYSICAL_SOURCE_PREFILL` changes. The generic plan preserves modality runs and the source tail checkpoint, bounds complete prefill prompts to 512 tokens and component tiles to 16, and keeps eligible logical batches at least 8 tokens without token/tensor-specific routing.
