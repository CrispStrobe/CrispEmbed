# Audited installation inside the original Josev GPU task

This source preparation reuses the exact archive-audit helpers from `e74df24f`
and the strict installed-owner selector from `8e42b2b4`. The independent CPU
archive-audit workflow and its historical source remain unchanged. This installer
belongs only to the genuine original CUDA reference bootstrap; it is not a CPU
Kaggle task, a submission command, or permission to retry unsupported hardware.

Before any wheel transfer, the new CLI requires the explicitly reviewed worker
checkout, frozen model contract, isolated virtual environment, original bootstrap
receipt, hosted task location and a fresh hardware query. Both the recorded and
current GPUs must meet the unchanged Turing/CUDA13 driver and memory bounds;
physical identities must agree. The bootstrap supplies an explicit setup gate.
The immutable57-wheel lock, package versions, model weights, four-case panel,
F32 math and all tolerances are preserved.

The installer processes one wheel at a time. It streams the exact pinned PEP658
sidecar and wheel into task-owned scratch, checks payload size/SHA, top-level
owner metadata identity/SHA, exact sidecar bytes and dependency declarations, then
rehashes the local wheel immediately before invoking pip. Pip receives only a
local file requirement with `--no-index --no-deps --require-hashes` and no cache.
The task removes only that temporary wheel directory afterward. Small owner and
sidecar metadata, per-wheel audit states, install logs and partial failures remain
in the result directory; wheel/model payloads never become result artifacts.

Any discrepancy stops setup before installing that wheel. Earlier authenticated
installs may exist in the disposable task venv, but no framework import, CUDA
smoke or model access follows the rejection. A successful setup requires all57
archive audits and installations, each installed owner version/origin/hash, pip
check, and the complete installed-environment guard with runtime imports disabled.
Only then can the existing bootstrap import the exact frameworks, verify their
origins, perform the CUDA smoke and enter the original worker. The outer audited
install retains the existing1,500-second bound. Transfers/installations use at most
1,380 seconds, reserving time for final checks, with one wheel in scratch.

A live sidecar failure or owner byte difference remains rejection. No dependency
normalization, lock rewrite or equivalence waiver is introduced. Installed package
metadata verification and archive verification measure separate barriers. This
preparation has only synthetic stdlib tests; actual wheel installation and original
capture require parent review and an approved GPU slot. No dispatch is included.
