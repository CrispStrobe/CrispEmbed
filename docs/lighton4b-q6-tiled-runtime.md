# Experimental physical Q6 tiled arithmetic

`CRISPEMBED_LIGHTON4B_PHYSICAL_Q6_TILED` stays default-off. The physical LightOn4B owner admits it only in the previously closed native CPU profile and with native layer projections enabled. It applies the pinned upstream Q6 block reduction generically to eligible batches of at least eight tokens, preserves legacy arithmetic below that threshold, and rejects cache reuse across modes. Original quantized weights, Q4 repack policy, HF profiles, public model fences and aliases remain unchanged.

The implementation reproduces the upstream integer block sum, weight-scale multiply and explicit activation-scale FMA without an expanded F32 weight cache. The [source-fed proof](https://github.com/CrispStrobe/CrispEmbed/blob/3c5f19c654d06ca3e0b52172f8f88e13c4e95386/docs/lighton4b-q6-tiled-helper-results.md) closes all 68 retained native/upstream operator outputs and every actual 140-row QKV output byte-exactly. Hosted structural controls cover nontrivial widths 256/768/9216, eligible production routing, false aliases and cache continuations/toggle rejection; all 38 checks pass.

The [complete observed A/B](https://github.com/CrispStrobe/CrispEmbed/blob/c58642e5b8faf80d40a659eb010ed2f87d661e6e/docs/lighton4b-q6-tiled-full-ab-results.md) retains strict OFF closure for all 282 table and 167 form score rows, intermediate stages, vision bytes, IDs and EOS. Adding only Q6 tiled arithmetic to the combined GDN/Q4-repack configuration changes table character edits from 348 to 337 of 607 and word edits from 97 to 95 of 106. Form character edits improve from 194 to 175 of 656, while word edits rise from 40 to 45 of 90. Both observed outputs meet their provisional upstream character/word floors; the form first-score RMS worsens from .1231 to .1528.

This is not numerical parity or shipping qualification. Original source graph boundaries differ from native chunking; the helper uses the generic batch rule without token-specific routing. Arabic and the frozen provisional panel remain pending. Existing single-gate negatives remain binding. No default, model recipe, public format, release or application alias is promoted.

The standalone `tools/q6-qkv-batch-probe` and `tools/q6-tiled-probe` retain source-backed operator reproduction; `tools/q6-tiled-full-ab` retains the closed observed decoded protocol. These reference probes and the structural test target are not installed as production artifacts. Runtime arithmetic is confined to the gated helper and its callers.
