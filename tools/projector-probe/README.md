# Pinned projector-only attribution draft

This reference probe loads no text checkpoint and performs no original BF16 forward. It authenticates all297 native protected vision tensors (F32 storage) and maps them to all298 publisher projector tensors. The additional source tensor is the documented temporal split of patch Conv3D into two Conv2D weights. Canonical F32 comparisons, native-to-F16 rounding comparisons and exact-BF16-value counts are reported separately; declared checkpoint names do not prove content identity.

Primary blueprint: llama.cpp commit `6c01da6278ab6c69ed67d9124806b50d2b299ba7`, [conversion](https://github.com/ggml-org/llama.cpp/blob/6c01da6278ab6c69ed67d9124806b50d2b299ba7/conversion/qwen3vl.py) `Qwen3VLVisionModel.modify_tensors`, [graph](https://github.com/ggml-org/llama.cpp/blob/6c01da6278ab6c69ed67d9124806b50d2b299ba7/tools/mtmd/models/qwen3vl.cpp) `clip_graph_qwen3vl::build`, and [shared graph](https://github.com/ggml-org/llama.cpp/blob/6c01da6278ab6c69ed67d9124806b50d2b299ba7/tools/mtmd/clip.cpp) `build_inp_temporal_merge`, `resize_position_embeddings`, `build_attn`.

The immutable publisher mmproj is672,423,200bytes. Only the native vision suffix is transferred:1,334,056,960bytes, verified individually against the already whole-file-authenticated native protected-source pack receipt. Total2,006,480,160bytes is below the2.1GB quota. No full F32 model or text GGUF is assembled. Weights remain on the remote worker. Canonical comparisons stream bounded chunks; patch temporal joining is limited to its6MB tensor.

The standalone source program uses pinned internal clip/preprocessor APIs, original observed-form RGB and exactly64–256 image-token settings, four threads, flash attention disabled. Both observer OFF/ON merged outputs must match the retained actual upstream feature hash exactly. The corrected reference-only patch names the existing learned-position tensor and captures selected F32 stages in the scheduler evaluation callback immediately after execution, before buffer reuse. The earlier postcompute/output-flag observer was invalid despite merged-output neutrality and remains preserved. If the live callback changes final output, stage interpretation fails closed. It changes no source arithmetic or product artifact. Non-contiguous, missing, nonfinite or unmaterialized stages are unsupported, never inferred to be zero.

After actual-source/observer closure, compare source normalized pixels reordered into native temporal/2×2 patch layout, patch+bias, interpolated position, patch+position and all24 visual block outputs against the retained composed-native arrays. Report raw hashes and FP64 RMS/max; weights and precision equivalence are independent controls. Native norms/intermediates absent from the retained export remain unsupported. A matching component does not qualify decoded output.

Draft checks: seven model-free controls cover the complete mapping and mutation rejection, temporal reconstruction, spatial patch layout and nonfinite values. Pinned source observer anchors were checked against exact primary files, including rejecting a repeated patch. Hosted compilation and independent review are required before submission. The worker is bounded to3,600seconds, two build/four compute threads,4GiB available RAM,8GiB scratch and2GiB output. Only projector encoding is allowed; no decoder or full greedy output is generated. No runtime fix or qualification claim follows automatically.

Preprocessing attribution separately captures actual C++ RGB reads, source resized uint8 RGB and normalized HWC/graph CHW. Native resized RGB is uniquely recovered from retained normalized patches and must exactly reproduce every native normalized value. Compare resized integer pixels independently of the two normalization formulas on the same source pixels. Patch+position and first-layer FFN residual identities must close bit-exactly on live captures; each selected callback must occur once. Canonical F16-round disagreements now report numeric differences, signed-zero counts and bounded samples rather than assuming a rounding transform.
