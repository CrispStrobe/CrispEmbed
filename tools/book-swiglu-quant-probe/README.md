# Frozen second image SwiGLU and Q6 replay

Reference-only tools for the frozen book second image tile (image rows 16–31).
This is a same-input operator replay; it performs no model forward, decoding,
recipe selection or runtime change. Rights-sensitive arrays and complete worker
reports remain in private retained artifacts.

The protocol authenticates the neutral upstream capture and the native observer
whose complete historical prefill hashes, every layer-zero tile and final cache
close exactly. Actual gate/up arrays must match before interpreting activation
arithmetic. Both pinned GGML profiles and the exact historical native Q6 tiled
helper are built on the authorized hosted CPU worker. Synthetic controls run
before the sole original 19,353,600-byte Q6 down tensor is fetched by verified
range and whole-tensor hash.

Required whole-output closures are native scalar activation, upstream fused
activation, native tiled scalar down, upstream graph fused down and native tiled
fused down. Public Q8_K conversion followed by the same down operator must also
reproduce the corresponding F32-input computation before interpreting code
changes. Generic native GGML raw reduction remains a separate measured route.
The report records scale/integer/sum changes and per-row output errors with
magnitudes; converter outputs are interventions, not captured internal buffers
or vocabulary IDs. No operator result establishes decoded quality.

The first hosted attempt failed during controller-source admission because a
read-only git query inherited the worker directory. It performed no build,
parameter transfer or operator/model computation. The corrected attempt gives
all direct git queries an explicit repository path; the numerical contract and
original inputs are unchanged.
