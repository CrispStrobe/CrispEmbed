Historical fused-ON baselines bind the exact failed partial producer plus its completed independent audit for book and receipt, and the inventory continuation plus its independent audit. Reused observed controls bind the exact six-arm producer, all its owned bytes and all 849 actual rows, while preserving the table/form BF16 regressions. Original source references, prepared pixels, input seals, labels, scorer and gate tuple stay fixed. This does not apply to the retained tested inference bundle.

Mount the completed fixed producer, tested controls/runtime, observed six-arm producer, prior fused baseline producers/audits and original fixed source references.
