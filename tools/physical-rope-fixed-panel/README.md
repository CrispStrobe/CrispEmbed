# Fixed physical RoPE diagnostic panel

This hosted-only controller runs the unchanged three selected cases in the
predeclared order: book OFF/ON, receipt OFF/ON, inventory OFF/ON. Both arms keep
physical SwiGLU enabled; only physical RoPE changes. Each case keeps its original
pixels, input seal, scorer, source reference, 1536-token cap and context budget.
The capped book is a valid negative baseline and must reproduce all 1536 old
fused rows, stages, text and stop state before its ON arm runs. Decoded negatives
do not stop the remaining cases; a failed artifact, input, resource, arithmetic
or baseline identity contract does.

The immutable candidate is `a8a22749ab0b757ae1f317b6fa5b84ffd148b939`.
Inference uses the byte-verified native binary and libraries retained by the
successful source-fed controls. Only the metadata preflight target and its
necessary dependencies are separately built from that identical candidate.
The successful observed screen and all its retained artifacts are authenticated
without repeating observed inference. Original source and BF16 references are
reused without model execution.

The observed screen restored source token parity on all three cases, while
worsening table/form edits against the original BF16 baseline. This panel is a
diagnostic continuation, with no default, release, application or quality
promotion. Full book text, token IDs and raw reports remain private and remote.
Public evidence may contain metrics and hashes only.
