# Original OvisOCR2 GPU quality reference

This hosted script captures one original vLLM 0.22.1 T4 auto-FP16 quality reference. It requires the reviewed successful V6 GPU receipt, original metadata and frontend service proofs, pinned checkpoint SHA, actual T4 driver and CUDA runtime, and exact source hashes before inference. The model runs with the original README image kwargs, greedy settings, GDN Triton prefill and the reviewed explicit `TRITON_ATTN` decoder override. The README's automatic FlashInfer decoder failed on this T4; this run does not claim backend equivalence.

The worker first freezes eight self-authored 448×448 synthetic pages from the canonical Ovis panel and verifies three separately reviewed realistic PNGs from the byte-identical public mirror of original artifact 12037153992. It checks their raw RGB, PNG and gold hashes before model initialization. The fixed caps are 256 for each synthetic case and 1024 for each realistic case. Heldout inputs are not used for calibration. The worker stores the actual vLLM token IDs, stop reason, selected-token logprobs when returned, raw and README-processed text, per-case time and memory observations, CER/WER, formatting and table cells. It retains each case immediately, including incomplete or failed outputs. A vLLM special stop omitted from returned IDs remains omitted and is labeled using its explicit stop reason.

The one resulting report is a small quality observation, not a native parity result or a public OCR benchmark. No weights or full-vocabulary logits are published. Submit only after a free GPU slot check; keep the large checkpoint in the hosted scratch space.
